# Jesus Campaign Church

Official website for Jesus Campaign Church in Pattom, Thiruvananthapuram,
with a branch in Wayanad, Kerala.

## Local development

```bash
npm install
npm run dev
```

The site includes the church story, Pattom and Wayanad location details,
ministries, Jesus Campaign Youth / House of Worship, visit planning, directions,
WhatsApp actions, and a contact form that prepares a WhatsApp enquiry.

## Production builds

```bash
npm run build
npx next build
```

The first command validates the Sites-compatible build. Vercel uses the Next.js
build configured in `vercel.json`.
